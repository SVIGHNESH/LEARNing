# Java DSA/CP Workspace

This workspace is set up for competitive programming and DSA practice in Java.

## Files
- `input.txt`: Place your input here.
- `output.txt`: Output will be written here.
- `DSATemplate.java`: Starter template for reading from `input.txt` and writing to `output.txt`.

## How to Run
1. Place your input in `input.txt`.
2. Compile the Java file:
   ```
   javac DSATemplate.java
   ```
3. Run the program:
   ```
   java DSATemplate
   ```
4. Check `output.txt` for results.
